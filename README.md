# EMERGENCY SUPPLIES - Frontend Implementation

This repository contains the user interface and client-side logic for EMERGENCY SUPPLIES. It is a dynamic web application built with vanilla web technologies, designed to interact with a MongoDB REST API for data persistence.

#Overview
This module handles the visual representation and user experience of the project. It retrieves data from a MongoDB backend and dynamically renders it using JavaScript.

#Tech Stack
* **HTML:** Semantic structure.
* **CSS:** Responsive layout and custom styling (Flexbox/Grid).
* **JavaScript:** DOM manipulation and Asynchronous API handling.
* **Database Integration:** MongoDB
